# Raw data layout

Place permitted local source files here. The public repository intentionally does not contain licensed source data.

```text
data/raw/
├── financial/      # all CSMAR financial-indicator exports
├── nonfinancial/   # all CSMAR governance/audit/internal-control exports
├── mda/            # 2013_2014.xlsx, 2015_2017.xlsx, 2018_2019.xlsx, 2020_2024.xlsx
├── dlut/           # dlut_sentiment.xlsx
├── violation/      # violation_data.xlsx (or original CSMAR filename)
└── industry/       # industry_data.xlsx
```

The files in these folders may be subject to license restrictions and are excluded from Git by default.
